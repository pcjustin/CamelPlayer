# CamelPlayer 使用說明

CamelPlayer 是 Windows 上的音樂播放器，可播放 FLAC、ALAC、WAV、AIFF、AAC、MP3 和 DSD（DSF、DSDIFF）檔案，無損音樂以 bit-perfect 送到 DAC。本說明介紹安裝、介面導覽、選擇輸出方式、DSD 播放與常見問題。[English](UserGuide.md)

## 安裝

1. 從專案的 GitHub Releases 頁面下載 `CamelPlayer-<版本>-win-x64.zip`。要確認下載無誤，可在 PowerShell 用 `Get-FileHash` 算出 SHA-256，與同一版的 `CamelPlayer-<版本>-SHA256SUMS.txt` 中對應的那一行比對。
2. 把整個 zip 解壓縮到可寫入的資料夾，例如 `C:\Apps\CamelPlayer`。所有檔案要放在一起，不需要安裝。
3. 執行 `CamelPlayer.exe`。程式沒有數位簽章，第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」：按 **其他資訊**，再按 **仍要執行**。

CamelPlayer 需要 64 位元的 Windows 10 1809 或更新版本，或 Windows 11。設定、媒體庫和紀錄檔存放在 `%LOCALAPPDATA%\CamelPlayer`，設定 › 重置與資料會顯示這個資料夾及其大小。要移除 CamelPlayer，刪除程式資料夾即可，需要的話也可以刪除資料資料夾。

第一次啟動會開啟簡短的入門引導：選擇淺色、深色或依 Windows 設定的外觀，加入音樂資料夾（本機磁碟或 NAS），再選擇輸出方式。在選擇資料夾的視窗中，按住 Ctrl 可以一次選取多個資料夾。媒體庫在背景掃描，專輯會陸續出現。引導可以略過，之後可在設定 › 介面 › **重新開啟入門引導** 再次開啟。

設定 › 介面 › **主題** 可隨時切換淺色、深色或依 Windows 設定。

關閉視窗後 CamelPlayer 會留在通知區域，媒體鍵和快捷鍵仍可使用；要結束程式請用通知區域圖示選單中的 **結束**，或在設定 › 介面 › **關閉視窗時** 改成直接結束。

## 介面導覽

**首頁** 顯示最近播放和最近加入的專輯，最下方是本月的聆聽時間、播放次數和最常播放的專輯。按這張卡片進入 **聆聽** 頁：上方的今天、本週、本月、今年和全部時間卡片，決定下方長條圖、最常播放的專輯、演出者和曲目（依播放次數或聆聽時間）以及播放紀錄的時段。**檢視全部** 會開啟完整清單。按標題列的返回鍵、Alt+← 或滑鼠的上一頁鍵回到首頁。

導覽列有 **專輯**（依標題、演出者、年份或加入日期排序）、**演出者**、**作曲家**、**類型**、**年份**、**曲目** 和 **資料夾**。專輯、演出者、作曲家和類型清單旁的字母可直接跳到清單中的那一段；視窗較矮時，兩個字母之間的圓點代表中間省略的字母。專輯頁依光碟列出曲目，並為其中的每種格式、位元深度和取樣率顯示一個標籤。演出者或作曲家會開啟自己的頁面：**曲目** 列出你最常播放的十首（沒播過的依年份和專輯順序），**檢視全部** 列出全部曲目；**專輯** 是專輯演出者為他的專輯，**參與演出** 是其他含有他曲目的專輯。專輯頁、演出者頁和播放列上的每個演出者名字都能點，會開啟那位演出者。一筆標註了好幾位演出者時，每一位都各自算數：「Aimer with chelly」、「A feat. B」、「A; B」一定會拆；「A & B」、「A, B」、「A / B」則要至少有一個名字也在媒體庫裡單獨出現過才拆。「Bob Marley & The Wailers」這樣的樂團仍是一位演出者，「Yo-Yo Ma, cello」也是。從標題列搜尋（Ctrl+F）：輸入時會顯示建議，按 Enter 列出所有結果。

按一下曲目即可播放。在曲目、專輯、演出者或資料夾上按右鍵，可選 **接著播放** 或 **加到佇列尾端**；先用 Ctrl 或 Shift 加按可選取多列。播放列右側的佇列按鈕會開啟播放佇列：拖曳項目可調整順序，按 Delete 可移除，佇列的 ⋯ 選單可清空佇列、將佇列儲存為播放清單，或開關 **播完後自動播放**。自動播放會在最後一首播完後，接著隨機播放最近 7 天沒聽過的媒體庫曲目。按播放列的封面可開啟正在播放的專輯。

在選取的項目上按右鍵，可選 **建立播放清單** 或 **加入播放清單**。播放清單可以播放、重新命名、拖曳調整順序，並用 **匯出 M3U8** 存成檔案；清單頁的 **匯入 M3U8** 可讀取 M3U8 和 M3U 檔案。曲目或專輯旁的愛心可標為最愛；演出者或作曲家可用他頁面上的愛心，或在名字上按右鍵標為最愛，**只顯示最愛** 會讓演出者和作曲家清單只列出最愛。**智慧清單** 會整理最近加入、最常播放、最近播放、從未播放的曲目和你的最愛，**最愛演出者** 先列出你的最愛演出者，再列出最愛作曲家。

| 按鍵 | CamelPlayer 在前景時 |
| --- | --- |
| Space | 播放或暫停 |
| Ctrl+→ / Ctrl+← | 下一首或上一首 |
| Ctrl+Shift+→ / Ctrl+Shift+← | 快轉或倒轉 10 秒 |
| Alt+← 或滑鼠的上一頁鍵 | 返回 |
| Ctrl+F | 搜尋媒體庫 |
| Delete | 移除選取的佇列或播放清單項目 |

全系統快捷鍵（Alt+Home 播放或暫停，Alt+Page Up 和 Alt+Page Down 切換上一首和下一首）在任何程式中都有效，可在設定 › 快捷鍵中更改。

## 更新

CamelPlayer 在啟動時以及執行期間每天一次向 GitHub 查詢是否有新版本，每次檢查只是向專案的 GitHub Releases API 發出一次查詢，不會送出任何關於你或你媒體庫的資訊。有新版本時，視窗上方會出現橫幅，提供 **更新**、**版本說明** 和 **略過這個版本**；關閉橫幅表示「稍後」。按下 **更新** 之前不會下載任何東西。

**更新** 會下載該版本的 zip 檔，並以該版本的 SHA-256 校驗值檢查；若正在播放，會先詢問是否重新啟動。CamelPlayer 關閉後，更新程式替換程式檔案，再啟動新版本。佇列和播放位置會恢復（暫停狀態），新版本會顯示自你原本的版本以來的所有變更。若程式資料夾受保護（例如位於 Program Files），Windows 會要求系統管理員權限。任何步驟失敗或新版本無法啟動時，會還原先前的版本以及設定和媒體庫，之後也不再自動提示該版本。

設定 › 介面 › **自動檢查更新** 可關閉啟動時與每天的檢查；設定 › 關於 › **檢查更新** 可隨時檢查。也可以手動更新：把新的 zip 解壓縮到原資料夾或新資料夾，設定和媒體庫都會保留。

## 選擇輸出後端

設定 › 播放 › 輸出後端 決定聲音如何送到裝置。每個後端各自保存裝置與設定。

| 後端 | 適用情況 | 說明 |
| --- | --- | --- |
| WASAPI 獨佔（預設） | 大多數情況 | Bit-perfect。「跟隨 Windows 預設」會在預設裝置改變時跟著切換；自行選定的裝置被拔除時會暫停播放。 |
| WASAPI 共用 | 需要和其他程式同時發聲 | 經過 Windows 混音器，一定會轉換，顯示為「已處理」。 |
| ASIO | DAC 有自己的 ASIO 驅動程式 | Bit-perfect，也是唯一支援原生 DSD 的後端。**開啟控制面板** 會顯示驅動程式自己的設定。 |
| Kernel Streaming | 沒有 ASIO、WASAPI 又不順的裝置 | 直接與驅動程式溝通。播放時 Windows 和其他程式都無法使用該裝置。 |

播放列右下角的標記會顯示目前的路徑：**Bit-perfect** 表示檔案的樣本原封不動送到裝置，**已處理** 表示經過轉換（共用模式、固定取樣率或你允許的轉換）。點一下格式那一行可看到每個處理步驟。設定中的「狀態」卡片列出輸出格式、模式、裝置緩衝和 underrun 次數；「設定值 ≠ 實際值」表示裝置無法接受某個已儲存的設定，並列出實際使用的值。

裝置無法直接接受檔案格式時，CamelPlayer 會跳過並通知你，未經允許不會轉換。把 **裝置無法直接接受檔案格式時** 設為 **轉換**，就能重新取樣、降混為立體聲或降低位元深度。**取樣率** 可讓所有 PCM 檔案固定以同一個取樣率輸出（顯示為「已處理」）；要 bit-perfect 播放請維持 **跟隨檔案**。

## DSD 播放

DSF 和 DSDIFF 檔案以原始 DSD 送到 DAC，方式有兩種，在各後端的 **DSD 輸出** 設定：

- **原生 DSD**（僅 ASIO，也是 ASIO 的預設）：驅動程式直接收到 DSD。
- **DoP（DSD over PCM）**（WASAPI 和 Kernel Streaming 的預設）：把 DSD 包進 24 位元 PCM 訊框，由支援 DoP 的 DAC 解開。DoP 需要 DSD 取樣率 / 16 的 PCM 取樣率，因此 DSD256 需要 705.6 kHz，DSD512 需要 1411.2 kHz，支援後者的裝置不多。

播放原始 DSD 時會出現 **DSD** 或 **DoP** 標記，表示音量和其他所有 PCM 處理都被略過。

**轉換為 PCM** 會以 **DSD 轉 PCM 取樣率**（88.2、176.4 或 352.8 kHz）把 DSD 轉成 PCM，給不支援 DSD 的 DAC 使用。若維持原生或 DoP 輸出，**裝置不接受原生 DSD 也不接受 DoP 時** 決定裝置拒絕時的做法：略過並通知你（預設），或轉換為 PCM。不支援以 DST 壓縮的 DSDIFF 檔案。

## 常見問題

**檔案被跳過，顯示「裝置無法以 bit-perfect 播放這個格式」。** 裝置不接受該檔案的取樣率、位元深度或聲道數。請確認選對了裝置、換一個 **樣本格式**，或允許轉換（見上文）。

**沒有聲音，或顯示「輸出裝置未連接」。** 打開 DAC 電源，在輸出裝置中選擇它。裝置接上或移除時清單會自動更新；按 **重新整理裝置清單** 可立即重新讀取。自行選定的裝置不會被自動換成別的裝置；請重新選擇，或改用「跟隨 Windows 預設」。

**DSD 播出很大的雜訊或嘶聲。** DAC 不支援 DoP（或驅動程式沒有原樣傳遞）。請把 DSD 輸出設為 **轉換為 PCM**。第一次在新裝置上播放 DSD 前，請先調低音量。

**CamelPlayer 播放時其他程式沒有聲音。** 獨佔模式、ASIO 和 Kernel Streaming 會獨佔裝置。按停止會立即釋放；暫停後則在 **暫停後釋放裝置** 設定的時間（預設 1 秒）後釋放。要和其他程式同時發聲，請改用 WASAPI 共用模式。

**切換格式時有爆音、開頭被吃掉或短暫無聲。** 有些 DAC 切換取樣率或在 PCM 與 DSD 之間切換時需要時間。請把 **格式切換後的靜音**（在「緩衝與時序」中）調高到 200–500 ms。

**斷音或劈啪聲。** 「狀態」卡片會計算 underrun 次數。請加大緩衝：ASIO 緩衝大小（或驅動程式的控制面板）、更長的 WASAPI 裝置週期或輪詢緩衝長度，或更長的 Kernel Streaming 緩衝長度。MMCSS 任務請維持 Pro Audio。

**媒體庫資料夾顯示為離線。** 磁碟或 NAS 分享目前無法連線。其中的曲目仍留在媒體庫中並標示為無法使用，資料夾恢復後就會回來。新檔案會自動找到；若標籤看起來沒有更新，可用設定 › 重置與資料 › **重建媒體庫** 重新讀取所有檔案，統計和播放清單都會保留。

**出現「CamelPlayer 修復了損毀的資料」。** 無法讀取的設定檔或媒體庫資料庫會以 `.bad` 副檔名保留在資料資料夾。設定會用上次啟動時保存的副本還原。媒體庫會用每日備份還原；備份在 CamelPlayer 閒置或結束時進行，所以之後的變更可能遺失。沒有可用的副本時，設定會回到預設值，或建立新的媒體庫，需要重新加入音樂資料夾。

**CamelPlayer 顯示資料是由較新的版本建立的。** 較新的版本已經升級了設定或媒體庫，之後又執行了較舊的 CamelPlayer。請改回較新的版本；較舊的版本沒有變動任何資料。

**快捷鍵沒有作用。** 設定 › 快捷鍵 會提示已被其他程式佔用的組合；請改按其他組合。

**出現「部分程式檔案損毀或遺失」。** 每個版本第一次啟動時，CamelPlayer 會把程式資料夾與正式版的檔案清單比對；也可以隨時在設定 › 關於 按 **檢查安裝**。**詳細資料** 會列出有問題的檔案。**修復** 會從 GitHub 重新下載同一個版本並替換程式檔案，設定和媒體庫都會保留。如果是防毒軟體隔離了檔案，請先在防毒軟體中還原，或把 CamelPlayer 資料夾設為例外。

**Windows 顯示找不到 DLL，或 CamelPlayer 完全開不起來。** 可能是 zip 沒有完整解壓縮、直接在 zip 裡執行，或防毒軟體刪除了檔案。請把整個 zip 重新解壓縮到單獨的資料夾，再從那裡執行 `CamelPlayer.exe`。

## 回報問題

到專案的 GitHub 頁面開一個 issue 並填寫表單。在設定 › 關於 中選擇 **建立診斷資料…**，把存下的 zip 檔附上。裡面有紀錄檔、設定、輸出裝置及其支援的格式、安裝檢查的結果，以及最近一次的當機報告。除非勾選 **包含檔案與資料夾路徑**，否則不會包含檔案和資料夾路徑。當機報告是 CamelPlayer 的記憶體快照，請只在你願意分享的地方附上診斷資料。
