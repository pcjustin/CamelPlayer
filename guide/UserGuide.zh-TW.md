# CamelPlayer 使用說明

CamelPlayer 是 Windows 上的音樂播放器，可播放 FLAC、ALAC、WAV、AIFF、AAC、MP3 和 DSD（DSF、DSDIFF）檔案，無損音樂以 bit-perfect 送到 DAC。本說明介紹安裝、選擇輸出方式、DSD 播放與常見問題。[English](UserGuide.md)

## 安裝

1. 從專案的 GitHub Releases 頁面下載 `CamelPlayer-<版本>-win-x64.zip`。要確認下載無誤，可在 PowerShell 用 `Get-FileHash` 算出 SHA-256，與同一版的 `CamelPlayer-<版本>-SHA256SUMS.txt` 中對應的那一行比對。
2. 把整個 zip 解壓縮到可寫入的資料夾，例如 `C:\Apps\CamelPlayer`。所有檔案要放在一起，不需要安裝。
3. 執行 `CamelPlayer.exe`。程式沒有數位簽章，第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」：按 **其他資訊**，再按 **仍要執行**。

CamelPlayer 需要 64 位元的 Windows 10 1809 或更新版本，或 Windows 11。設定、媒體庫和紀錄檔存放在 `%LOCALAPPDATA%\CamelPlayer`，設定 › 重置與資料會顯示這個資料夾及其大小。更新時把新的 zip 解壓縮到原資料夾或新資料夾即可，設定和媒體庫都會保留。要移除 CamelPlayer，刪除程式資料夾即可，需要的話也可以刪除資料資料夾。

第一次啟動會開啟簡短的入門引導：加入音樂資料夾（本機磁碟或 NAS），再選擇輸出方式。媒體庫在背景掃描，專輯會陸續出現。引導可以略過，之後可在設定 › 介面 › **重新開啟入門引導** 再次開啟。

關閉視窗後 CamelPlayer 會留在通知區域，媒體鍵和快捷鍵仍可使用；要結束程式請用通知區域圖示選單中的 **結束**，或在設定 › 介面 › 關閉視窗時 改成直接結束。

## 選擇輸出後端

設定 › 播放 › 輸出後端 決定聲音如何送到裝置。每個後端各自保存裝置與設定。

| 後端 | 適用情況 | 說明 |
| --- | --- | --- |
| WASAPI 獨佔（預設） | 大多數情況 | Bit-perfect。「跟隨 Windows 預設」會在預設裝置改變時跟著切換；自行選定的裝置被拔除時會暫停播放。 |
| WASAPI 共用 | 需要和其他程式同時發聲 | 經過 Windows 混音器，一定會轉換，顯示為「已處理」。 |
| ASIO | DAC 有自己的 ASIO 驅動程式 | Bit-perfect，也是唯一支援原生 DSD 的後端。**開啟控制面板** 會顯示驅動程式自己的設定。 |
| Kernel Streaming | 沒有 ASIO、WASAPI 又不順的裝置 | 直接與驅動程式溝通。播放時 Windows 和其他程式都無法使用該裝置。 |

播放控制下方的標記會顯示目前的路徑：**Bit-perfect** 表示檔案的樣本原封不動送到裝置，**已處理** 表示經過轉換（共用模式、固定取樣率或你允許的轉換）。點一下格式那一行可看到每個處理步驟。設定中的「狀態」卡片列出輸出格式、模式、裝置緩衝和 underrun 次數；「設定值 ≠ 實際值」表示裝置無法接受某個已儲存的設定，並列出實際使用的值。

裝置無法直接接受檔案格式時，CamelPlayer 會跳過並通知你，未經允許不會轉換。把 **裝置無法直接接受檔案格式時** 設為 **轉換**，就能重新取樣、降混為立體聲或降低位元深度。**取樣率** 可讓所有 PCM 檔案固定以同一個取樣率輸出（顯示為「已處理」）；要 bit-perfect 播放請維持 **跟隨檔案**。

## DSD 播放

DSF 和 DSDIFF 檔案以原始 DSD 送到 DAC，方式有兩種，在各後端的 **DSD 輸出** 設定：

- **原生 DSD**（僅 ASIO，也是 ASIO 的預設）：驅動程式直接收到 DSD。
- **DoP（DSD over PCM）**（WASAPI 和 Kernel Streaming 的預設）：把 DSD 包進 24 位元 PCM 訊框，由支援 DoP 的 DAC 解開。DoP 需要 DSD 取樣率 / 16 的 PCM 取樣率，因此 DSD256 需要 705.6 kHz，DSD512 需要 1411.2 kHz，支援後者的裝置不多。

播放原始 DSD 時會出現 **DSD** 或 **DoP** 標記，表示音量和其他所有 PCM 處理都被略過。

**轉換為 PCM** 會以 **DSD 轉 PCM 取樣率**（88.2、176.4 或 352.8 kHz）把 DSD 轉成 PCM，給不支援 DSD 的 DAC 使用。若維持原生或 DoP 輸出，**裝置不接受原生 DSD 也不接受 DoP 時** 決定裝置拒絕時的做法：略過並通知你（預設），或轉換為 PCM。不支援以 DST 壓縮的 DSDIFF 檔案。

## 常見問題

**檔案被跳過，顯示「裝置無法以 bit-perfect 播放這個格式」。** 裝置不接受該檔案的取樣率、位元深度或聲道數。請確認選對了裝置、換一個 **樣本格式**，或允許轉換（見上文）。

**沒有聲音，或顯示「輸出裝置未連接」。** 打開 DAC 電源，在輸出裝置中選擇它，再按 **重新整理裝置清單**。自行選定的裝置不會被自動換成別的裝置；請重新選擇，或改用「跟隨 Windows 預設」。

**DSD 播出很大的雜訊或嘶聲。** DAC 不支援 DoP（或驅動程式沒有原樣傳遞）。請把 DSD 輸出設為 **轉換為 PCM**。第一次在新裝置上播放 DSD 前，請先調低音量。

**CamelPlayer 播放時其他程式沒有聲音。** 獨佔模式、ASIO 和 Kernel Streaming 會獨佔裝置。請改用 WASAPI 共用模式，或把 **暫停後釋放裝置** 設成較短的時間。

**切換格式時有爆音、開頭被吃掉或短暫無聲。** 有些 DAC 切換取樣率或在 PCM 與 DSD 之間切換時需要時間。請把 **格式切換後的靜音**（在「緩衝與時序」中）調高到 200–500 ms。

**斷音或劈啪聲。** 「狀態」卡片會計算 underrun 次數。請加大緩衝：ASIO 緩衝大小（或驅動程式的控制面板）、更長的 WASAPI 裝置週期或輪詢緩衝長度，或更長的 Kernel Streaming 緩衝長度。MMCSS 任務請維持 Pro Audio。

**媒體庫資料夾顯示為離線。** 磁碟或 NAS 分享目前無法連線。其中的曲目仍留在媒體庫中並標示為無法使用，資料夾恢復後就會回來。新檔案會自動找到；若標籤看起來沒有更新，可用設定 › 重置與資料 › **重建媒體庫** 重新讀取所有檔案，統計和播放清單都會保留。

**快捷鍵沒有作用。** 設定 › 快捷鍵 會提示已被其他程式佔用的組合；請改按其他組合。

## 回報問題

到專案的 GitHub 頁面開一個 issue 並填寫表單。在設定 › 關於 中選擇 **建立診斷資料…**，把存下的 zip 檔附上。裡面有紀錄檔、設定、輸出裝置及其支援的格式，以及最近一次的當機報告。除非勾選 **包含檔案與資料夾路徑**，否則不會包含檔案和資料夾路徑。當機報告是 CamelPlayer 的記憶體快照，請只在你願意分享的地方附上診斷資料。
